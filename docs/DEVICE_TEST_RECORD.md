## 系统安全和基本操作

- [ ] Windows 密码、PIN 或 Windows Hello 仍能正常登录；存在可用的恢复方式。
- [ ] 可以在 GUI 中安装、查询、停止、重新启动和卸载后台服务与登录组件。
- [ ] 新版安装保留既有配置；卸载时可以选择保留或删除设置。
- [ ] 锁屏会话与首次登录、注销后的登录、其他 Windows 用户、远程桌面会话之间的触发条件符合设计。
- [ ] TPM 可用时可以保存和读取凭据；TPM 不可用时仍可以通过 DPAPI 保存。
- [ ] 在测试环境验证清除 TPM 密钥后旧密文不能被解密，以及重新设置密码后的恢复方法。

## 蓝牙连接与认证

- [ ] Android 认证服务启动后，Windows 显示真实名称或解锁服务占位名称。
- [ ] 表格列、左侧面板、浅色／深色主题和 100%／150%／200% DPI 下的布局清晰。
- [ ] BLE 广播暂时消失时保留列表记录并显示“上次 dBm”；约 3 分钟无新广播后移除。
- [ ] 历史列表记录不能直接触发解锁；低安全性模式须有已配对设备与新近信号。
- [ ] Windows 成功读取 Android 65 字节公钥，并与 Android 指纹一致。
- [ ] 自动模式在已锁定会话完成随机挑战认证；手动模式能确认、拒绝、取消和超时。
- [ ] 蓝牙关闭／开启、App 后台运行、手机重启和厂商省电设置后的行为已经记录。
- [ ] 信号强度阈值与近距离、远距离使用场景相符；中继攻击不在 RSSI 安全保证范围内。

## RustDesk 连接（启用时填写）

- [ ] 服务端能够产生所选 SSE 事件；API Key 仅授予 `events.read`。
- [ ] 验证目标设备和连接方 ID、认证成功事件、多个连接与最后一条连接结束。
- [ ] 验证网络断开、重复事件、过期事件、SSE 恢复与关闭自动锁定设置。
- [ ] 服务端审计事件的身份验证和来源检查已经单独确认。
